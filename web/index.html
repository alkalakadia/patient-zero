Patient Zero

When an AI agent gets poisoned, find everything it touched and undo only that.

A hacker slips one instruction into the notes your AI agents share. The agents follow it and ship the hacker's code. Patient Zero finds the poisoned note, proves which changes it caused, and, after you approve, undoes only those.

● Not just GitHub: same engine, other systems
Payments in Delta (live on Databricks)Three AI agents pay 40 real suppliers from Databricks sample data. Someone edits the payment-policy page; payments go to the attacker's account. Patient Zero finds the edit and fixes only those rows in Delta, proven by Change Data Feed.
Any agent that logs to MLflow (no code changes)An ordinary support agent with one line of MLflow logging refunds orders to an attacker after a wiki edit. Patient Zero reads the logs it already writes and finds the edit and the notes that copied it. From logs alone it shows the evidence; connecting Patient Zero adds proof and undo.
Each new system needs one detection rule and, where the system allows it, an undo connection. Anything that can't be undone goes to a person with the corrected details.
